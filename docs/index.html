Telegram · VK · Linux · Windows

Cursor Linux Telegram Bot

Управляйте машиной из мессенджера: сообщения уходят локальному агенту, ответы возвращаются в чат.

GitHub Установка

Схема работы

Telegram / VK  →  cursor-linux-tg-bot  →  Cursor CLI | OpenRouter | orc

Возможности

  • Диалог с сохранением сессии между сообщениями
  • Потоковые ответы и статус выполнения
  • Telegram и VK — можно включить оба или один
  • Голосовые сообщения через Whisper
  • Провайдеры: Cursor CLI, OpenRouter API, OpenRouter CLI (orc)
  • Git: авто-коммит, /push, /pull, /undo
  • Очередь сообщений с сохранением на диск
  • Автозапуск и автоперезапуск службы

Быстрая установка (Linux)

git clone https://github.com/ZTex275/CursorLinuxTgBot.git
cd CursorLinuxTgBot
chmod +x install.sh uninstall.sh update.sh
sudo ./install.sh

Быстрая установка (Windows)

git clone https://github.com/ZTex275/CursorLinuxTgBot.git
cd CursorLinuxTgBot
.\install.ps1

Нужны Python 3.11+, Cursor Agent CLI и PowerShell от администратора.

Команды в чате

КомандаДействие
/startСправка
/newНовая сессия
/mode agent|planРежим работы
/provider …Сменить провайдера
/statusСтатус агента и git
/commit, /push, /pull, /undoРабота с git
/stopПрервать задачу и очистить очередь
Текст или голосЗадача для агента

Безопасность

Агент может выполнять shell-команды и менять файлы в workspace. Обязательно укажите allowed_user_ids и ограничьте права пользователя службы.
